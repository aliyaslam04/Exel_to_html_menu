# Excel to HTML Menu Generator

Python script that converts any CSV/Excel product list to a responsive HTML restaurant menu.

## How it works
1. Client gives you products.csv
2. Run: python excel_to_menu.py
3. Get menu.html ready to upload

## Why clients love it
- Saves 5 hours of manual work
- No need to write HTML for each product

## Tech
Python, CSV, HTML generation
